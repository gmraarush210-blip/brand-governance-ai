# Demo Script (about 3 minutes)

1. **Problem (20s):** multi-author, multi-tool publishing; review is manual and late.
2. **Submit (20s):** paste the fictional campaign draft (`sample_content`) as Creator.
3. **Findings (45s):** show a prohibited term, an unsupported "fastest in the world" claim, a wrong founded year, masked email. Point at the cited section + version, the uncertainty label, and the optional fix.
4. **Human authority (30s):** Creator cannot resolve a High finding. Switch to Reviewer, accept with a comment.
5. **Revise (20s):** edit the draft, save as revision 2, re-review; show original preserved.
6. **Approve (20s):** Manager approves; show audit trail.
7. **Insights (15s):** recurring issues and most-rejected rules.
8. **Honest limits (10s):** text/PDF only; images staged; synthetic data; not a certification.
